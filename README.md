# OILPULSE — Fuel Intelligence Thailand (PWA)

แอปเว็บติดตั้งได้ (PWA) สำหรับดูราคาน้ำมันจากแหล่งข้อมูลทางการ ใช้ได้บน Android, iPhone, แท็บเล็ต และคอมพิวเตอร์ ผ่านเว็บเบราว์เซอร์ ไม่ต้องติดตั้ง Android Studio

## ความสามารถในรุ่นนี้
- หน้าแสดงราคาน้ำมันแบบภาษาไทย พร้อมตัวกรองแบรนด์
- เชื่อมต่อข้อมูลราคาบางจากผ่าน Web Service ทางการ และอ่านราคาจากหน้าเว็บ Caltex ทางการ
- แสดงราคาและการเปลี่ยนแปลงเมื่อมีข้อมูลจากต้นทาง
- อ่านราคาอนาคตของบางจากจากฟิลด์ PriceTomorrow และแสดงเมื่อราคาแตกต่างจากราคาปัจจุบัน
- GitHub Actions ตรวจสอบแหล่งข้อมูลทุก 30 นาที และบันทึก feed เมื่อข้อมูลเปลี่ยน
- เก็บประวัติราคาที่อุปกรณ์และแสดงกราฟเมื่อมีข้อมูลสะสม
- ตั้งรายการน้ำมันที่ต้องการติดตาม และแจ้งเตือนในเบราว์เซอร์เมื่อเปิดแอป/เว็บอยู่
- ติดตั้งเป็น PWA, ใช้งานหน้าแอปที่แคชไว้แบบออฟไลน์ได้
- ไม่มีการสร้างราคาสมมติ ถ้าต้นทางอ่านไม่ได้จะไม่แสดงตัวเลขแทน

## แบรนด์และขอบเขตข้อมูล
- บางจาก (BCP): เชื่อม API ทางการ ซึ่งส่งราคาปัจจุบัน/เมื่อวาน/วันถัดไปและข้อความวันเวลามีผล
- Caltex: อ่านรายการราคาจากหน้าเว็บทางการ
- PTT, Shell, PT และ Susco: มีตัวกรองเตรียมไว้ แต่จะไม่แสดงราคาจนกว่าจะมีแหล่งข้อมูลที่อ่านได้และตรวจสอบได้ในระบบ
- EPPO แสดงไว้เป็นแหล่งอ้างอิงราคากลางและข้อมูลย้อนหลัง แต่หน้าแสดงผลบางช่วงมี placeholder/โหลดข้อมูลแบบไดนามิก จึงยังไม่ถูกใช้เป็นตัวเลขราคาของแอปโดยอัตโนมัติ

## ติดตั้งผ่าน GitHub Pages (ครั้งแรก)
1. ดาวน์โหลด ZIP นี้และแตกไฟล์
2. สร้าง Repository ใหม่บน GitHub ตั้งชื่อเช่น `oilpulse`
3. อัปโหลดไฟล์และโฟลเดอร์ทั้งหมดจาก ZIP เข้า Repository ที่ branch `main` (ต้องเห็น `index.html` อยู่ระดับบนสุด)
4. เข้า **Settings → Pages** แล้วเลือก **Build and deployment → GitHub Actions**
5. เข้าแท็บ **Actions** เลือก workflow `Deploy OILPULSE to GitHub Pages` แล้วกด **Run workflow** หากยังไม่เริ่มทำงานเอง
6. เมื่อ workflow สำเร็จ เปิด URL GitHub Pages ที่ GitHub แสดงให้ (รูปแบบ `https://ชื่อผู้ใช้.github.io/oilpulse/`)
7. เข้าแท็บ **Actions** เลือก `Refresh official fuel prices` แล้วกด **Run workflow** เพื่อดึงราคาครั้งแรก

> หลังจากนั้น GitHub Actions จะตรวจข้อมูลทุก 30 นาทีอัตโนมัติ หาก workflow ไม่ทำงาน ให้ตรวจหน้า Actions และสิทธิ์ Actions ใน Settings → Actions → General ว่าอนุญาตให้ workflow เขียน repository ได้

## ติดตั้งลงมือถือ Android
1. เปิด URL GitHub Pages ด้วย Chrome
2. รอให้หน้าเว็บโหลด แล้วแตะปุ่ม `＋` ติดตั้ง (ถ้าเบราว์เซอร์แสดง) หรือแตะเมนู ⋮ → **ติดตั้งแอป / Add to Home screen**
3. ยืนยันติดตั้ง แล้วเปิด OILPULSE จากไอคอนบนหน้าจอ
4. หากต้องการรับแจ้งเตือนขณะเปิดแอป ให้กด **เปิดการแจ้งเตือน** และอนุญาตสิทธิ์ Notification

บน iPhone/iPad ให้เปิดด้วย Safari → Share → Add to Home Screen

## ข้อจำกัดที่ต้องทราบอย่างตรงไปตรงมา
- GitHub Pages เป็นเว็บโฮสต์แบบ static จึงไม่สามารถส่ง Push Notification ขณะปิดแอปได้ด้วยตัวเอง รุ่นนี้แจ้งเตือนผ่าน Notification เมื่อเปิดแอปและตรวจพบข้อมูลใหม่เท่านั้น การแจ้งเตือนเบื้องหลังจริงต้องเพิ่ม Push service + server เก็บ subscription และ VAPID keys
- การตรวจทุก 30 นาทีเป็นรอบที่ระบบดึงข้อมูล ไม่ได้หมายความว่าปั๊มเปลี่ยนราคาทุก 30 นาที
- ระบบจะแสดงราคาอนาคตล่วงหน้าเฉพาะเมื่อแหล่งข้อมูลต้นทางส่งค่าราคาอนาคตมาให้ เช่น Bangchak PriceTomorrow; ไม่ได้คาดการณ์ราคาเอง
- ราคามาตรฐานอาจไม่รวมภาษีบำรุงท้องถิ่นและอาจต่างกันตามจังหวัด/สถานี
- ข้อมูลประวัติในกราฟจะเริ่มสะสมจากวันที่ผู้ใช้เปิดแอป และข้อมูลที่เปลี่ยนแปลงจาก feed เท่านั้น ไม่ได้มีฐานข้อมูลย้อนหลังเต็มรูปแบบติดมาให้

## โครงสร้าง
- `index.html`, `styles.css`, `app.js` — แอปหลัก
- `manifest.webmanifest`, `sw.js` — PWA install/offline
- `assets/` — ไอคอนแอป
- `feeds/live-prices.json` — ข้อมูลราคาที่เผยแพร่ให้หน้าแอป
- `scripts/fetch_live.py` — ตัวดึงข้อมูลจากแหล่งทางการ
- `.github/workflows/pages.yml` — deploy GitHub Pages
- `.github/workflows/update-live-prices.yml` — refresh ราคาอัตโนมัติ

## แหล่งข้อมูลต้นทาง
- Bangchak API: https://oil-price.bangchak.co.th/ApiOilPrice2/th
- Caltex: https://www.caltex.com/th/motorists/products-and-services/fuel-prices.html
- EPPO: https://www.eppo.go.th/energy-price/oil-retail-price-today/
